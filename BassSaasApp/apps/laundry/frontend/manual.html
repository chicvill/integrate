앱 ID: laundry · 버전 1.0.0 · API 경로 /api/laundry

1. 고객 이용 절차

  1. 보드에서 사용 가능 장비의 ▶ 코스 선택을 누릅니다.
  2. 코스를 고르면 요금이 투입 금액 칸에 자동으로 채워집니다.
  3. (선택) 완료 알림용 휴대폰 번호를 입력하고 결제하고 시작을 누릅니다.
  4. 완료 예정 시각이 지나면 장비가 자동으로 수거 대기로 바뀝니다.
  5. 세탁물을 꺼낸 뒤 🧺 수거 완료를 누르면 다음 고객이 사용할 수 있습니다.

4. 관리자 기능

포털에서 관리자 계정으로 로그인하면 장비 카드에 점검 버튼이 나타납니다.
  • ⛔ 점검 등록: 사유를 입력하면 장비가 점검 중으로 바뀌고 고객 결제가 차단됩니다.
  • 🛠 점검 완료: 수리 후 누르면 사용 가능으로 복귀합니다.
  • 모든 시작/수거/점검 이력은 포털의 변경 이력에 행위자와 함께 기록됩니다.

5. 자주 묻는 질문

Q. 시간이 지났는데 아직 가동 중으로 보여요.
A. 화면은 15초마다 갱신됩니다. 🔄 새로고침을 누르면 즉시 반영됩니다.

Q. 결제 버튼을 두 번 눌렀어요.
A. 처리 중에는 버튼이 잠겨 중복 결제가 발생하지 않습니다.
