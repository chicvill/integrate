# Grammar Quest (초3 ~ 고3 영문법 퀘스트 - PC & 스마트폰 웹)

PC(데스크톱/노트북)와 스마트폰(모바일 웹) 어디서나 키보드, 마우스, 터치 제스처, 그리고 마이크 음성 인식(Web Speech API)으로 편리하게 학습할 수 있는 **초3 ~ 고3(수능) 전 학년 맞춤형 무한 영문법 학습 웹 애플리케이션**입니다.

모든 학습 예문은 **수학(Mathematics), 과학(Science), 기술(Technology), 공학(Engineering), 인공지능(AI)** 등 최첨단 미래 기술 도메인의 전문 어휘와 실제 연구 상황을 바탕으로 구성되어, 영문법 학습과 동시에 미래 핵심 테크 어휘를 자연스럽게 습득할 수 있습니다.

## 🌟 주요 특징

### 1. 🔬 STEM & AI 첨단 기술 특화 예문 엔진
기존의 일상 회화 위주 예문을 탈피하고, 5대 첨단 과학기술 도메인의 엄선된 어휘로 모든 문장을 구성했습니다:
* 📐 **수학 (Mathematics)**: 알고리즘 복잡도, 수학 공식 및 방정식 계산, 위상수학 정리 증명, 수치 파라미터
* 🔭 **과학 (Science)**: 우주 천문학, 화성 탐사선(Rover), 중력파 및 블랙홀 충돌, 입자 가속기, 생체 DNA 분석
* 💻 **기술 (Technology)**: 파이썬 코딩, 빅데이터 실시간 분석, 양자 암호학, 클라우드 아키텍처, 슈퍼컴퓨팅
* ⚙️ **공학 (Engineering)**: 휴머노이드 로봇 설계, 전기차 배터리, 반도체 팹 제조 공학, 자율비행 초음속 드론, 청정 수소 에너지
* 🤖 **인공지능 (Artificial Intelligence)**: 딥러닝 인공 신경망(Neural Networks), 머신러닝 모델, 컴퓨터 비전 진단, 알고리즘 편향 제어

### 2. ⚡ 6단계 학년별 정규 교육과정 문법 엔진
* **초등 3~4학년**: Be동사 현재형(`am/are/is`), 지시대명사(`This/That/These/Those`), 기초 인칭대명사
* **초등 5~6학년**: 현재진행형(`be + -ing`), 조동사 `can`, 기본 의문사(`What/Who/Where`)
* **중학 1학년**: 일반동사 3인칭 단수(`-s/-es/has/goes`), 과거시제 불규칙, 부정/의문문(`do/does/did`)
* **중학 2학년**: to부정사, 동명사 목적어(`enjoy/finish + -ing`), 수동태(`be + p.p.`), 비교급(`-er than`)
* **중학 3학년**: 현재완료(`have + p.p.`), 관계대명사(`who/which/that`), 접속사 `that`
* **고등 1~3 / 수능**: 수능 빈출 5대 어법 (주어-동사 수일치, `that vs what`, 가정법 과거/과거완료, 분사구문)

### 3. ♾️ 무한 문장 절차적 생성 (Procedural Generation)
* 고정된 문제 은행을 넘어, 주어·동사·목적어·시제 문법 규칙을 실시간 조합하여 수천~수만 개의 자연스러운 첨단 기술 예문 무한 생성

### 4. 🎮 5가지 인터랙티브 퀘스트 모드 (문제별 자동 균등 출제)
매 세트(10문제)마다 다음 5가지 퀘스트 유형이 골고루(각 2문항씩) 무작위 출제되어 다채로운 학습 경험을 제공합니다:
* **선택형 (Choice)**: 4지선다형 그리드 + 키보드 번호키(`1`~`4`)/방향키, 모바일 화면 원터치 및 음성 선택
* **단어 어순 배열 (Sentence Scramble)**: PC 마우스 드래그 & 드롭 및 모바일 원터치 블록 스왑(Tap to Swap)을 통한 문장 조립
* **무보기 말하기 (Free Speaking)**: 보기를 숨기고 힌트만 보고 정답 단어를 마이크에 직접 발음
* **듣기 평가 (Listening & Answer)**: 브라우저 내장 원어민 영어 TTS로 문장을 듣고 빈칸 단어 구술
* **문장 전체 섀도잉 (Shadowing)**: 원어민 발음을 듣고 문장 전체를 마이크로 따라 읽어 실시간 발음 정확도 채점 (정답 후에도 언제든 재도전 가능)

### 5. 🔬 AI 원어민 발음 정밀 클리닉 & 음소 교정 코칭 (Pronunciation Clinic)
학습자가 문장을 따라 읽었을 때 원어민 발음과의 미세한 차이점을 분석하여 1:1 맞춤 교정 가이드를 실시간 제공합니다:
* 👄 **`V vs B` 마찰음 진단**: 윗니로 아랫입술 안쪽을 물고 성대를 울려 진동을 내는 `V`와 단순 양순음 `B`의 조음 차이점 설명
* 💨 **`P vs F` 공기마찰 진단**: 두 입술을 마주치지 않고 윗니-아랫입술 사이로 바람만 거칠게 내뿜는 `F`와 파열음 `P`의 구별법 가이드
* 👅 **`R vs L` 혀 위치 정밀 코칭**: 혀끝이 입천장에 절대 닿지 않는 공중 부양 굴림음 `R`과 윗니 뒤 잇몸에 단단히 밀착되는 `L`의 혀 위치 시각화
* 🦷 **`TH` 치간음 (`θ`/`ð`) 진단**: 앞니 사이로 혀끝을 1cm 내미는 정석 치간음과 한국식 `S/D` 오독 방지 팁
* ⚡ **STEM 어휘 강세(Accent) 코칭**: `pa-RAM-e-ter`, `AL-go-ri-thm`, `au-TON-o-mous` 등 한국인이 흔히 틀리는 첨단 어휘의 강세 음절 대문자 분해 표기
* 📊 **단어별 발음 일치도 트랙**: 녹음된 음성을 원문과 단어별로 1:1 대조하여 정확한 단어(✅)와 발음 교정이 필요한 단어(⚠️)를 한눈에 식별

### 6. 💻📱 PC & 스마트폰(모바일 웹) 완벽 반응형 UI
* **PC 환경**: 키보드 단축키(`1`~`4` 번호키, `Enter`/`Space` 확인, `V` 마이크 토글, `C`/`M`/`F1` 핵심 문법, `F` 전체화면, `H` 도움말, `ESC` 닫기) 및 마우스 조작
* **스마트폰/태블릿 환경**: 모바일 전용 1열 세로 카드 레이아웃, 모바일 터치 최적화(300ms 딜레이 제거, 원터치 블록 스왑), 가로 스와이프 학년 선택 바
* **전체화면 집중 모드**: 상단 `⛶ 전체화면` 버튼 클릭 또는 `F` 키로 방해요소 없는 몰입형 학습 환경 지원
* **Web Audio API**: 레트로 아케이드 효과음 내장

## 🚀 실행 및 접속 방법

### 1. 로컬 개발 서버 실행
```bash
node server.js
```

### 2. 기기별 접속 안내
* **PC / 노트북**:
  - Chrome, Edge, Safari, Firefox 등 웹 브라우저 주소창에 `http://localhost:3000` 입력
  - 키보드 번호키(`1~4`)와 `Enter`, `V`(마이크)로 쾌속 플레이
* **스마트폰 / 태블릿 (모바일 웹)**:
  - PC와 동일한 Wi-Fi 공유기에 연결된 스마트폰의 모바일 브라우저(Safari, Chrome)를 실행
  - 주소창에 PC의 로컬 IP 입력 (예: `http://192.168.0.x:3000`)
  - 화면 터치와 스마트폰 내장 마이크를 활용하여 음성 학습 진행

### 🐳 Docker로 실행
```bash
docker compose up -d
```
브라우저에서 `http://localhost:3000` 접속
