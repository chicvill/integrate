# MQnet Integrated Workspace - Architecture Overview

## 1. 플랫폼 비전 & 모노레포 구조
MQnet 플랫폼은 단일 코드베이스(Mono-Repo)에서 공통 커널(`shared/`), 리버스 프록시 게이트웨이(`gateway/`), 그리고 다수의 독립 비즈니스 서비스(`apps/`)를 경량·고효율로 구동하는 스마트 빌딩/공간 운영 통합 솔루션입니다.

```text
c:\Users\USER\Desktop\Workstation\integrated/
├── gateway/                     # 중앙 통합 인증 및 리버스 프록시 게이트웨이 (포트 8000/9000)
│   ├── main.py                  # 라우팅, JWT 인증 검증, 서브앱 리버스 프록시, NoCacheStaticFiles
│   └── portal.html              # 중앙 마스터 포털 UI (단일 대시보드)
├── apps/                        # 도메인별 독립 실행 가능한 비즈니스 마이크로앱
│   ├── rent2/                   # 차세대 스마트 모바일 임차관리 솔루션 (포트 9016)
│   ├── rent/                    # 1세대 임차/지출 관리 솔루션
│   ├── studycafe/               # 1호점/2호점 무인 스터디카페 관제 솔루션 (포트 9002)
│   ├── selfstudy/               # 관리형 독서실/셀프스터디 관제 솔루션 (포트 9005)
│   ├── store/                   # 가맹점/매장 포스 및 키오스크 (포트 9006)
│   ├── photos/                  # AI 사진관 / 이미지 아카이빙 (포트 9008)
│   ├── files/                   # 보안 클라우드 파일함 (포트 9009)
│   └── deployer/                # 원격 배포 및 인프라 모니터링 (포트 9004)
├── shared/                      # 공유 핵심 라이브러리 (Shared Kernel)
│   ├── auth/                    # JWT 토큰, 패스워드 해싱, RBAC 권한
│   ├── core/                    # SQLite WAL 최적화, 스토리지 모니터링 데몬
│   └── storage/                 # 파일 업로드 및 클라우드 동기화
├── data/                        # 통합 데이터베이스 및 영구 저장소
│   └── integrat.db              # 중앙 SQLite 메인 DB (WAL 모드)
└── .agents/skills/              # Antigravity 시스템 검증 및 가이드 스킬
    └── mqnet-system-navigator/  # 본 스킬 (구조 파악, 규칙 검증, 자동 테스트)
```

## 2. 듀얼 모드 아키텍처 (Dual-Mode Operation)
모든 비즈니스 앱은 소스 코드 변경 없이 두 가지 모드로 동작할 수 있도록 설계되었습니다:

1. **중앙 멀티테넌트 SaaS 모드 (`/api/{app_id}/`)**:
   - 게이트웨이(`gateway/main.py`)를 통해 모든 트래픽이 집중되며, 본사 중앙 데이터베이스(`integrat.db`)와 단일 암호화 볼트를 공유합니다.
   - 본사 총괄 관리자가 다중 지점(Multi-Branch)을 원격에서 일괄 감시 및 통제합니다.

2. **독립 패키지 Standalone 모드 (`/api/`)**:
   - `scripts/export_app.py`를 통해 원클릭으로 추출되어 특정 고객의 사내 인트라넷, 폐쇄망 또는 단독 PC에 설치됩니다.
   - 단독 실행 포트를 점유하고 로컬 DB(`app.db`)를 사용하여 외부 인터넷 연결 없이 100% 자립 구동됩니다.
   - 프론트엔드의 `getApiBase()` 유틸리티가 접속 URL 환경을 감지하여 API 경로를 자동 전환합니다.

## 3. 포트 할당 및 네트워크 매핑
| 포트 (Port) | 애플리케이션 (Service) | 역할 및 엔드포인트 |
| :--- | :--- | :--- |
| **8000 / 9000** | **통합 게이트웨이 (Gateway)** | 중앙 로그인, 포털 UI (`/portal.html`), API 프록시 |
| **9016** | **스마트 임차관리 (rent2)** | 모바일 특화 원룸/빌딩 임대료 수납 (`/index.html`) |
| **9002** | **스터디카페 (studycafe)** | 무인 좌석 예약, 키오스크, 바코드 출입문 관제 |
| **9005** | **셀프스터디 (selfstudy)** | 관리형 독서실 입실/퇴실, 부모 알림 포털 |
| **9006** | **스마트 스토어 (store)** | 무인 매장 POS, 상품 결제 및 재고 관리 |
| **9008** | **AI 포토스튜디오 (photos)** | AI 프로필/스냅샷 생성 및 갤러리 |
| **9009** | **보안 파일 드라이브 (files)** | 가맹점 계약서 및 문서 보관소 |
| **9004** | **데플로이어 (deployer)** | 서비스 상태 헬스체크 및 핫패치 배포 |
