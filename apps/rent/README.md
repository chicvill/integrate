# 🏢 29개실 원룸 임차료 관리 시스템 (Rent Management)

101호, 201~605호, 701~703호 총 29개실 규모의 다가구/원룸 임대차 전문 관리 웹 애플리케이션입니다.

## ✨ 주요 기능

1. **호실별 임대차 계약 관리**
   - 호실 드롭다운 선택 (101호, 201~605호, 701~703호 총 29개실)
   - 임차인 인적사항, 입주 상태(입주중/퇴실/예약)
   - 임대 형태(월세/전세), 납부 주기(선불/후불)
   - 보증금, 월세, 월 관리비, 입퇴실 청소비, 계약 기간
2. **당월 수납 및 미납 관리**
   - 당월 수납 완료 여부 체크 및 미납금 현황 표시
   - 납부 영수 내역 관리
3. **지출 장부 및 회계 관리**
   - 건물 수리비, 공과금, 승강기 정기 점검비 등 일자별 지출 내역 기록
   - 지출 장부 모달을 통한 내역 조회 및 합계 집계
4. **엑셀(CSV) 내보내기**
   - 호실별 수납 현황 및 장부 데이터를 CSV 형식으로 즉시 다운로드
5. **독립 운영 매뉴얼 제공 (`manual.html`)**
   - A4 고대비 흑백 인쇄 및 PDF 저장 기능 포함 (`@media print` 최적화)

## 🚀 실행 방법

### 로컬 단독 실행
브라우저에서 `index.html` 파일을 직접 열거나 웹 서버로 실행:
```bash
# Python 간단 웹서버 실행 예시
python -m http.server 9014 --directory apps/rent
```

### MQnet 통합 플랫폼 연동
- 통합 게이트웨이 포트 9000 및 단독 포트 9014에서 접근 가능합니다.
