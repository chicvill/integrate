1. 시스템 개요 및 접속 계정 체계

단일 로그인 포털에서 입력된 아이디에 따라 본사 관리 센터, 지점 관제, 일반 사용자 페이지로 0.1초 만에 자동 분기됩니다:

로그인 ID 기본 패스워드 권한 (Role) 접속 페이지 주요 권한
admin 1212 본사 총괄 최고관리자 /branches.html 전 지점 등록/폐점, 이용료 수납, 등업 승인
admin01 1212 제1매장 점주실장 /index.html?branch=main 본점 전용 데이터 관제 및 아이템 관리

일반 회원 개인 비밀번호 일반 사용자 (User) /index.html 서비스 자율 이용 및 관리자 등업 신청

2. 다중 매장(Multi-Branch) 관제 운영법

  1. 지점 셀렉터(상단 헤더): [🏢 전체 매장 (통합 관제) ▼] 드롭다운에서 원하는 지점을 선택하면 해당 지점의 데이터만 격리 표시됩니다.
  2. 신규 가맹점 1-클릭 등록: [➕ 매장 등록] 버튼을 클릭하고 고유 매장 코드(예: branch-sinchon), 매장명, 연락처, 주소를 입력하면 즉시 등록 완료됩니다.
💡 매장 격리 원칙: 각 지점 관리자는 자신이 속한 지점의 데이터만 제어할 수 있으며, 타 지점의 기밀 데이터나 본사 가맹비 수납 정보는 조회할 수 없습니다.

3. 본사 솔루션 이용료 수납 관리 (Billing)

본사 관리 포털(branches.html)에서 가맹점별 SaaS 구독 이용료를 실시간 관리합니다:

  • 요금제 플랜: 베이직(월 5만원), 프리미엄 관리형(월 15만원), 엔터프라이즈(월 25만원) 지원.
  • 수납 상태 뱃지: 완납 ✅, 결제 대기 ⏳, 연체/미납 🚨 실시간 표기.
  • 1-클릭 수납 확인: 가맹점의 입금 확인 시 [완납확인] 버튼을 누르면 당월 수납 처리 완료.

4. 점주/실장 등업 신청 및 본사 승인 절차

  1. 개인 가입: 가맹점주 및 관리자도 초기에는 일반 회원으로 가입합니다.
  2. 등업 신청: 회원 대시보드에서 [점주 등업 신청] 클릭 후 희망 지점과 가맹점 증빙 사유를 제출합니다.
  3. 본사 원클릭 승인: 본사 관리자가 branches.html의 [👥 점주/실장 등업 신청 관리] 탭에서 [승인] 버튼을 클릭하면 즉시 관리자 권한과 매장 배정이 완료됩니다.

5. 자주 묻는 질문(FAQ) 및 트러블슈팅

Q. 지점 관리자가 로그인했는데 전체 매장 데이터가 보입니다.

A. 해당 계정이 superadmin으로 지정되어 있는지 확인하십시오. 지점 관리자는 assigned_branch_id가 올바르게 매핑되어 있어야 격리 관제 모드로 동작합니다.

Q. 새로운 매장을 생성했는데 목록에 즉시 나타나지 않습니다.

A. 브라우저 새로고침(F5)을 누르거나 대시보드 상단의 지점 드롭다운을 확인하십시오. NoCacheStaticFiles 캐시 방어가 적용되어 있어 즉시 동기화됩니다.
